# GCT marketing website

The public site is temporarily a season countdown. Approved work-in-progress marketing pages live behind the preview password. The new visual editor lets authorized GCT teammates edit those pages without code, save drafts, review desktop/mobile, publish content to the protected site and restore earlier versions. Publishing content does not remove the countdown or deploy a redesigned public homepage.

Piff is the intended handoff user. Editor authentication uses the existing GCT account and an explicit editor membership; the shared preview password never grants editing rights. Drafts, history and membership are private. Images and videos uploaded for the website are public website assets.

Creators join free. Campaign and sporting claims must remain accurate. The existing approved page design and content are the starting point; this feature adds editing controls rather than replacing the design.
