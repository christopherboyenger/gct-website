# GCT marketing website

The public site is temporarily a season countdown. Current marketing pages live behind the preview password. The visual editor uses those same Home, Creators, Brands, Courses and Events templates. Authorized teammates edit without code, autosave private drafts, review desktop/mobile and submit saved snapshots to a GitHub pull request. Merging the PR applies its content to the website build. There is no direct publishing action and the countdown remains in place.

Chris and Piff are the handoff users. Editor authentication uses the existing GCT account and an explicit editor membership; the shared preview password never grants editing rights. Drafts, history and membership are private. Submitted snapshots are committed to the website repository. Uploaded images and videos are public website assets.

Creators join free. Campaign and sporting claims must remain accurate. The existing approved page design and content are the starting point; this feature adds editing controls rather than replacing the design.
