# GCT visual editor

Mode: Operate. Inherit the current GCT preview's restrained Geist typography, pale neutral surfaces, black text, blue selection accents, and crest + GCT identity. The editor is a task surface: fixed top toolbar, one inspector panel, a responsive page canvas. Keep drafts, saving, conflict, published, expired session and error states visible and explicit. Publishing requires reviewing a concrete summary. Disabled controls explain what is needed.

Do not redesign the marketing pages while adding editability. Text is escaped, styling uses validated controls, and page layout remains responsive. The canvas supports direct selection and inline text entry; the inspector provides text, image, link, size and color controls. Global style and page metadata have separate tabs. Website images are selected from the existing library or uploaded by authorized editors.
