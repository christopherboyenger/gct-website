# GCT visual editor

Mode: Operate. Inherit the current GCT preview's restrained Geist typography, pale neutral surfaces, black text, blue selection accents and existing identity. The editor is a task surface: fixed toolbar, inspector and responsive canvas. Keep drafts, saving, conflicts, queued PRs, PR links, merged/closed results, expired sessions and errors visible. Save to PR requires reviewing the saved page summary. Disabled controls explain what is needed. The canvas preserves the current website's own page design.

Do not redesign the marketing pages while adding editability. Text is escaped, styling uses validated controls, and page layout remains responsive. The canvas supports direct selection and inline text entry; the inspector provides text, image, link, size and color controls. Global style and page metadata have separate tabs. Website images are selected from the existing library or uploaded by authorized editors.
